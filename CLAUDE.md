# CLAUDE.md

Guidance for AI coding agents (Claude Code and others) working in this repo. Humans: see CONTRIBUTING.md.

## What this is

An open-source AI ordering agent for quick-service restaurants. Customers say or type what they want; the agent builds the cart from the menu, asks only for missing choices and the owner's order questions, and the order goes to the kitchen (POS).

## Commands

```sh
pnpm install
pnpm dev                          # API on :8787 and web on :3000
pnpm test                         # all unit tests (no API key needed)
pnpm typecheck
pnpm menu                         # print the demo menu
pnpm --filter @foa/agent eval     # grade the real LLM on evals/demo-orders.json (needs a key in .env)
```

## Layout

- `packages/core`: menu schema, cart engine, menu search, owner questions, shared API types (`src/api.ts`), demo menu.
- `packages/agent`: LLM agent. `actions.ts` (pure order actions), `tools.ts` (AI SDK tools wrapping them), `prompt.ts`, `run.ts`, `model.ts` (provider choice).
- `apps/server`: Hono API under `/api`, PGlite locally or Postgres via `DATABASE_URL`, POS adapter (`pos.ts`), speech provider (`speech.ts`, ElevenLabs).
- `apps/web`: Next.js pages: ordering link, kiosk/iPad, kitchen screen, owner settings, embed script.
- `evals/demo-orders.json`: sample orders with expected carts; used by unit tests and the LLM eval.

## Rules that must not break

- The model changes the order only through tools; every tool call is validated by the cart engine against the menu.
- Prices come only from menu data, and the server re-prices and re-validates the cart at checkout.
- Allergen information is never generated by the model. Only show what the menu lists, with "please confirm with staff".
- Required owner questions block checkout.
- Keep `@foa/core` free of server and UI dependencies; keep the agent provider-agnostic (Anthropic, OpenAI, OpenRouter).
- The demo menu (Patty & Co.) is fictional. Don't add real brand names or trademarks.

## Conventions

- TypeScript strict, ESM, Zod for anything crossing a boundary. Money is integer cents.
- Add or update tests with every behaviour change; add eval cases for new ordering behaviour.
- Never commit `.env` or anything in `.data/`.
