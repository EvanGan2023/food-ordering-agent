# Contributing

Thanks for helping. This project is licensed under Apache-2.0, and contributions are accepted under the same licence.

## Set up

Requires Node 22+ and pnpm 10.

```sh
pnpm install
cp .env.example .env      # add an API key to try the AI agent (optional)
pnpm dev                  # API on http://localhost:8787, web on http://localhost:3000
pnpm test
```

Tap ordering, the kitchen screen and all tests work without an API key.

## Making a change

1. Open an issue first for anything bigger than a small fix, so we can agree on the approach.
2. Branch from `main`, keep the change focused, and add tests. New ordering behaviour should also get cases in `evals/demo-orders.json`.
3. Run `pnpm typecheck` and `pnpm test` before pushing; CI runs both.
4. Open a pull request describing what changed and how you tested it.

## Sign your commits (DCO)

We use the [Developer Certificate of Origin](https://developercertificate.org/). It's a statement that you have the right to submit your contribution. Add a sign-off line to every commit:

```sh
git commit -s -m "Fix modifier pricing for meals"
```

This adds `Signed-off-by: Your Name <you@example.com>` using your git name and email.

## Rules worth knowing

- The agent must only change orders through tools that are validated against the menu.
- Allergen information is never generated by the AI.
- Money is integer cents.

See `CLAUDE.md` for the full list and the repo layout.
